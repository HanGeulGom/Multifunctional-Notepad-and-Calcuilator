예외 처리한 계산기가 가장 핵심인 프로그램입니다. <br />
실행 후 '창작' 탭의 '계산기'를 누르시면 계산기 창이 뜹니다. <br />
해당 프로그램에서 내부 조작을 일부러 이상하게 시도해 보십시오. 예외 처리를 통해 예측 가능한 행동들을 사전에 막아놨기 때문에 안내 메시지가 안뜬 채 버그가 걸리거나 프로그램이 꼬여 종료되지 않을 것입니다. <br />
만약 계산기에서 헛점을 찾았다면 'dachan@gmail.com'으로 연락 주시길 바랍니다. <br />
아래는 계산기 사용 방법입니다. (사용방법은 '도움말' -> '메뉴얼' -> '계산기' 탭에서도 확인 가능합니다.)<br /><br />

1. 사용방법 및 안내사항 <br />
 ㄴ 1-1. 공학 계산기를 띄우는 기능입니다. 계산이 필요 할 때 사용하기 좋습니다. <br />
 ㄴ 1-2. (사용방법 0/2) : 텍스트창(숫자가 입&출력 되는 부분)에 직접 키보드로 수를 입력하거나, <br /> 
            마우스로 숫자 버튼을 눌러 원하는 수를 만듭니다. <br />
 ㄴ 1-3. (사용방법 1/2) : 수를 입력 한 뒤 원하는 계산식 버튼을 마우스로 클릭합니다. (키보드 사용 불가) <br /> 
             * '=' 버튼을 누르기 전 수식은 한번에 최대 30회까지 입력 가능합니다. <br />
             * '=' 버튼을 눌러 계산을 완료하면 기존의 수식 기록은 사라지고 결과값만 남습니다. <br />
 ㄴ 1-4. (사용방법 2/2) : '=' 버튼을 입력하여 결과 값을 확인합니다. <br /> 
 ㄴ 1-5. 본 계산기는 우선순위 기능을 지원하지 않습니다. <br /> 
           따라서 모든 계산은 입력된 순서대로 순차계산을 진행합니다. <br /><br />
           
2. 버튼 설명 <br />
 ㄴ 2-1. 'AC' : 'All Clear'의 약자로 현재 입력된 숫자 및 그 이전의 모든 계산과정을 지웁니다. <br />
 ㄴ 2-2 'CE : 'Clear Eentry'의 약자로 현재 입력된 숫자만 지웁니다. <br />
 ㄴ 2-3 'Prev' : 'Previous'의 약자로 현재 입력된 숫자를 지우고 가장 최근데 입력된 수식으로 돌아갑니다. <br />
 ㄴ 2-4 'Pi' : 'π'값을 텍스트창에 입력합니다. 소수점 9자리까지 입력됩니다. <br />
 ㄴ 2-5 'OFF' : 계산기의 전원을 꺼 텍스트창을 닫고 모든 버튼을 비활성화 시킵니다. <br />
                    입력 된 수식은 초기화되지 않고 유지됩니다. <br />
 ㄴ 2-6 'ON' : 계산기의 전원을 켜 버튼과 텍스트창을 활성화 시킵니다. <br />
 ㄴ 2-7 'Backspace' : 텍스트창의 숫자를 우측부터 하나씩 지웁니다. <br />
 ㄴ 2-8 'Radian' : 삼각함수를 계산할 때 텍스트창 숫자를 Radian(라디안) 값으로 취급하여 계산합니다. <br />
 ㄴ 2-9 'Degree' : 삼각함수를 계산할 때 텍스트창 숫자를 Degree(도) 값으로 취급하여 계산합니다. <br />
